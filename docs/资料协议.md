# 资料协议

各项时间以 UTC 保存，园区按 UTC+08:00 查当地班次。所有资格时间区间左闭右开。roles 列出工种当前要求的科目，accepts 表示某处考点的成绩在哪一科和截止日期可被当地认作报考材料或申请材料。它不是其他片区的工作资格。scores 是每科的出分原文，成绩有效截止与互认政策截止各自独立。certificates 是历史签发资料，scope 是当时引用的成绩。exams 的 seats 各场次独立。

policyNotices 列出互认结束和对应片区。examClaims 仅是报考人提出的席位申请。proofLetters 是曾发到单位的班次证明索引。scoreRevisions 指明复核结果及被更正的原考试科目。
