# 服务接口与领域规则说明

所有时间使用 UTC、左闭右开区间 `[from, until)`。服务仅依赖 Node.js 22 标准库。

## 启动

```bash
node src/http.js          # 默认端口 3000，可用 PORT 覆盖
npm test                  # 运行全部领域与端到端测试
```

## 参与者与请求头

除只读查询外，每个请求都需通过请求头表明参与者；缺失或越权返回 `403`。

| 头 | 含义 |
| --- | --- |
| `x-actor-id` | 参与者稳定编号 |
| `x-actor-type` | `centre-operator` / `reviewer` / `issuer` / `contractor` / `regulator` |
| `x-actor-ref` | 关联标识：考点编号、片区编号或承包商编号（按类型解释） |

权限边界：

- **centre-operator** 只能维护本考点考场、锁定本考点考试、给本考点已签到者录成绩；
- **reviewer** 是唯一可在事后提出成绩更正/撤销的角色，原成绩与复核结果各自留档；
- **issuer** 按片区处理材料（完整/暂缓/拒签）、签发、暂停后替换、不成立与重签；
- **contractor** 只能经 `/contractor-view` 看本承包班组：怎么排、哪段缺证及原因类别，不含分数与证照编号；
- **regulator** 可核查含已不成立证照在内的完整档案与审计日志。

## 接口一览

### 规则与互认

- `GET /regions/:region/rule-versions`：按施行日期排列的规则版本
- `POST /regions/:region/rule-versions`：发布新施行版本（`from` 必须晚于当前版本；`roles`/`accepts` 缺省继承上一版）
- `GET /regions/:region/acceptance?issuer=&subject=&at=`：某时点互认是否有效

互认有效需同时满足：生效版本的 `accepts` 含该考点+科目且未到截止；最近一条 `policyNotice` 未将其关闭。成绩有效期与互认截止分别判定。

### 考务

- `POST /exams`：考点创建考场（座位数按场次独立）
- `POST /exams/:id/claims`：报考。容量内 `reserved`，超出 `waitlisted`；允许先占座
- `GET /exams/:id/claims`、`GET /claims/:id/eligibility?at=`：报考单与逐科资格（含报名后规则变化提示）
- `POST /exams/:id/lock`：下发考试，锁定科目与人员，之后拒绝新报考
- `POST /exams/:id/check-ins`：补考当天签到，按**当天**规则与互认证据判定；被拒释放席位并立即重判候补
- `POST /exams/:id/rejudge`：候补重新判定（资格与空座都重算，已签到者永不被挤掉）
- `POST /claims/:id/cancel`：取消预留并触发候补递补
- `POST /exams/:id/scores`：只能给本考点、已签到者、锁定科目的当场成绩
- `POST /scores`：合作考点分次送分（同一科可多次送，每次独立留档；缺科仍为待定）
- `POST /scores/:id/revisions`：复核员更正或撤销（`passed` 布尔，`revoked` 可选）

### 发证

- `POST /cert-cases`：建立发证材料，返回 `complete` / `incomplete` / `rejected`
- `POST /cert-cases/:id/hold` / `reject`：暂缓（记待补科目）/ 拒签结案
- `POST /cert-cases/:id/issue`：仅完整材料可签；签发瞬间重新核查，失效则转回暂缓
- `POST /certificates/:id/replace-evidence`：用新成绩替代失效依据，按当次施行条款逐科重核，不做无条件拼接；恢复后生效日只向前，不追认
- `POST /certificates/:id/invalidate`：确认不成立，记录保留可核查
- `POST /certificates/:id/reissue`：基于新材料重签，新编号、新生效日、标注 `reissueOf`
- `GET /certificates/:id/file`：证照完整档案（事件链 + 每条依据的出分原文与复核链）

依据失效（撤销/复核推翻）只让 `scope` 依赖该成绩的证照进入 `suspended`；片区撤互认不暂停已发的本地资格证照，只阻止新申报引用外区成绩。

### 班次资格证明

- `POST /shifts/:id/proofs`：班组为具体班次、具体工人申请证明
- `GET /shifts/:id/evaluation?worker=&at=`：整段覆盖评估，返回覆盖段与逐段缺口
- `GET /contractor-view?shift=`：承包商受限视图
- `GET /audit-log`：只增审计日志

证照区间无缝接续（前段 `until` 等于后段 `from`）可共同覆盖横跨午夜的班次；任何小段无法覆盖都逐段给出时间与原因类别：
`NO_CERTIFICATE` / `CERTIFICATE_EXPIRED` / `CERTIFICATE_SUSPENDED` / `CERTIFICATE_INVALID` / `MISSING_SUBJECT`。

证据推翻按发生时点分三种处理：

| 时点 | 处理 |
| --- | --- |
| 班次开始前 | 证明状态翻转为 `denied`，班组可见新缺口并补人 |
| 班次进行中 | 原结论不改写，附加 `SUPERVISOR_REVIEW_REQUIRED` 告警，提示主管立即复核 |
| 班次结束后 | 仅追加事后获知影响（`letterImpacts`），不把当时结论改成从未确认 |

## 状态机摘要

```
examClaim: reserved ──签到──▶ checked-in
                 ├──拒绝──▶ denied（释放席位，候补重判）
                 ├──取消──▶ cancelled
                 └──满座──▶ waitlisted ──递补──▶ reserved
certCase:   incomplete / complete / rejected → issued → closed
certificate: issued ⇄ suspended（替换恢复）；issued → invalid（留档）→ reissue 新证
```
