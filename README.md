# 跨区补考、证照续接和班次资格证明

`data/records.json` 保存用于业务联调的虚构资料，包含分地区互认证据和考务容量相关记录。各表用稳定标识关联，字段定义见[资料协议](docs/资料协议.md)，服务接口与规则判定见[服务接口说明](docs/服务接口.md)。

运行环境为 Node.js 22.23.4，只使用 Node.js 标准库。可在项目根目录运行 `npm test`，检查样本字段、引用、领域规则与随附的联调接口。

## 代码结构

```
src/
  time.js         左闭右开区间、时点版本选择、覆盖合并与缺口计算
  errors.js       领域错误与 HTTP 状态码映射
  store.js        内存集合 + 只增审计日志 + 联调资料装载
  policy.js       按施行日期版本化的科目组合与互认范围
  evidence.js     成绩出分/复核留档、本地与外区证据可用性
  access.js       考点、复核员、发证方、承包商、监管方权限
  exams.js        席位预留/候补、下发锁定、当天签到、出分
  certificates.js 材料三态、签发、暂停、替换重核、不成立与重签
  shifts.js       班次整段覆盖、缺口原因、班前/班中/班后证据事件
  service.js      应用门面，装载资料并接线跨模块事件
  http.js         node:http 的 JSON 接口（node src/http.js 启动）
test/             node:test 领域测试与 HTTP 端到端测试
```

## 联调资料中的主线

资料本身构成一条完整时间线：river 片区 14:00 停止对 school-n theory 的互认；lark 的旧证 16:00 到期；夜班 15:30–19:00 横跨到期点；exam-r1 仅 1 个座位，lark 预留、ash 候补；16:20 复核推翻 lark 的外区 theory 成绩。服务装载时回放这些事件：证照 `cert-r1` 进入暂停核验、候补在签到拒绝后可递补、夜班证明带主管复核告警并逐段给出缺证时间与原因类别。
